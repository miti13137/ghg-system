本機自動備份與還原

資料變更前會保留最近 30 份本機備份；建議定期另存 JSON 至安全位置。本機 SQLite 備份包含已上傳的佐證檔案；JSON 下載只包含索引。

資料備份與還原

JSON 包含設定、排放源、係數、活動數據、索引及查證事項，不包含佐證檔案。匯入會取代目前所有資料，請先備份。

此輸出是內部盤查資料及查證工作底稿，不代表已符合所有法規申報格式或已完成第三方查證。需另外補齊間接排放顯著性準則、完整盤查方法、基準年重算規則、品質保證程序等正式報告內容。

Excel 批次匯入／匯出（本機預覽版）

請先下載「現有資料」範本修改，保留紀錄編號以便更新。空白範本適合首次建立。匯入先比對、不會立即寫入；確認後才更新。正式資料請勿存放於公開程式庫。

② 上傳 Excel 並預覽比對
